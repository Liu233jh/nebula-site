六件事，覆盖从起稿到交付的完整链路。每一条都对应一个具体操作，不是概念清单。

01结构化起稿

02版式自动排版

按内容量自动决定分栏、留白和标题层级，不用手动拖对齐。

03配图与风格统一

同一项目里所有配图共用一套色板和笔触，换一张不会跳戏。

每次生成存档，可以并排对比两版差异，也可以整段回退。

06批量套版

06 / NOTES

关于这个演示

这些价格可以真的下单吗？

不能。品牌、定价、指标和操作示例全部是编造的，页面不接支付通道，也没有注册入口。它存在的唯一目的，是演示版式、配色和动效做法。

页面里的能力描述是真实功能吗？

不是。上面六条能力是围绕“AI 创作工作台”这个虚构设定写的文案，用于撑起一个有信息量的版式，不对应任何真实产品实现。

排版和数据是怎么做的？

单文件 HTML，零外部依赖：线稿以 base64 内嵌，动效为原生 CSS 与一小段 JS，数字滚动用 requestAnimationFrame，滚动揭示用 IntersectionObserver。没有引入任何框架或 CDN 资源。
